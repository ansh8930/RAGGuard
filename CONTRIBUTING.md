# Contributing to RAGGuard

Thanks for your interest! Open an issue describing a bug or improvement before larger changes.

## Local setup

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

Add tests for any behavior change, document new APIs, and submit a focused pull request.
Do not commit API keys, user documents, generated caches, or proprietary evaluation datasets.
Be respectful in issue and PR discussions. Maintainers review contributions as time permits.
